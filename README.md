# 🧠 OpenAI Assistant API

Servidor backend construido con **Express** que expone endpoints para interactuar con la API de OpenAI.

---

## 🚀 Características

- Express como framework web
- Comunicación con la API de OpenAI
- Separación de capas (controladores, servicios, rutas)
- Uso de variables de entorno
- Compatible con desarrollo local (`npm run dev`)

---

## 📦 Instalación

1. **Clonar el repositorio**

```bash```
git clone https://github.com/tu-usuario/tu-repo.git
cd tu-repo


2. **Instalar las dependencias**

npm install

3. **Configurar variables de ambiente**

Crear archivo .env en la raiz del proyecto, y guiarse con .envexample

4. Modo desarrollo

npm run dev
